Construa o futuro com GitHub

GitHub é a plataforma onde pessoas e equipes criam, compartilham e melhoram projetos de software em conjunto.

O que é GitHub?

Um ambiente baseado em Git para armazenar código, acompanhar mudanças e colaborar em projetos de qualquer lugar.

Colaboração

Trabalhe em equipe com pull requests, revisões de código e discussões organizadas.

Versionamento

Registre cada alteração e acompanhe a evolução do projeto com segurança.

Automação

Use ferramentas de integração contínua para testar e entregar software com mais agilidade.
